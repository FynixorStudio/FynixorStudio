## <img src="https://img.shields.io/badge/01-Overview-007acc?style=flat-square&logo=readme&logoColor=white" alt="Overview">

**Fynixor Studio** adalah studio digital satu orang. Gue bangun produk sendiri lewat **Vorhex Store**, terima kerjaan dari luar lewat **Lumina Worksite**, dan sisanya masih tahap pengembangan.

- **Core focus**: website, bot Telegram/WhatsApp, script, automation, backend, dan integrasi API.
- **Produk sendiri**: panel, cloud/RDP, script, dan SMM di bawah Vorhex Store.
- **Eksperimen**: VTuber Agency (talent & content creator) dan MBD (security research & tooling).
- **Cara kerja**: dari nol sesuai kebutuhan — ide, desain, implementasi, serah terima, maintenance.
- **Lingkungan**: Android (Termux), Windows RDP, Linux, dan cloud.

### Featured project: mcpfs

**mcpfs** adalah local-first MCP config manager — satu perintah untuk sync & distribute konfigurasi MCP server ke banyak agen sekaligus.

- **Target**: Claude Code, Cursor, OpenCode, Codex CLI, Claude Desktop, dan lain-lain.
- **Pendekatan**: local-first, konfigurasi tetap di tangan user.
- **Bahasa**: Go.

<a id="faq"></a>

## <img src="https://img.shields.io/badge/09-FAQ-fd7e14?style=flat-square&logo=help&logoColor=white" alt="FAQ">

<details>
<summary><b>Fynixor Studio itu perusahaan?</b></summary>
<br/>
Bukan perusahaan berbadan hukum. Ini nama studio dan wadah untuk produk serta layanan yang gue kerjain sendiri. Unit yang belum berjalan ditandai jelas sebagai "dalam pengembangan".
</details>

<details>
<summary><b>Terima kerjaan dari luar?</b></summary>
<br/>
Terima, lewat Lumina Worksite: website, bot Telegram/WhatsApp, script, automation, backend, dan integrasi API. Bisa lewat Fiverr, Telegram, atau email.
</details>

<details>
<summary><b>Dikerjain pakai apa?</b></summary>
<br/>
Campuran: Android/Termux, Windows RDP, Linux, dan cloud, tergantung kebutuhan project. Stack harian: PHP, JavaScript/Node.js, Python, HTML/CSS, Firebase, dan MySQL.
</details>

<details>
<summary><b>MBD itu apa?</b></summary>
<br/>
Unit untuk riset dan pembuatan tools keamanan. Semua pengujian dilakukan hanya pada sistem sendiri atau yang ada izin tertulisnya.
</details>

<details>
<summary><b>Project open-source mana yang bisa dilihat?</b></summary>
<br/>
Cek <a href="https://github.com/FynixorStudio/mcpfs">mcpfs</a> untuk manajer konfigurasi MCP dan <a href="https://github.com/FynixorStudio/yokotofs-telegram-control">yokotofs-telegram-control</a> untuk bot control berbasis PHP.
</details>

<details>
<summary><b>Berapa lama pengerjaan project?</b></summary>
<br/>
Tergantung scope dan kompleksitas. Estimasi dan milestone dibahas di awal sebelum development dimulai.
</details>
