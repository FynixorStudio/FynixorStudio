**Fynixor Studio** — studio digital satu orang, berbasis di Indonesia, sejak 2023. Produk sendiri lewat **Vorhex Store**, jasa lewat **Lumina Worksite**, eksperimen lewat **VTuber Agency** dan **MBD**.
